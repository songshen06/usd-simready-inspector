Workflow 做了什么
  • 资产识别：分类为 decor，使用 36 个相近参考资产辅助选择尺寸和碰撞策略。
  • 尺寸处理以 8 x 8 x 10 cm 作为参考目标范围，并使用 0.04 的统一缩放保持原始比例；最终 authored bbox 约为 3.96 x 2.68 x 8 cm。参考目标不是把三轴强行拉伸到同一个尺寸，而是给自动化 authoring 一个物理尺度约束。
  • 朝向处理是把源资产的 Y-up 坐标系转换为输出 Stage 的 Z-up；实现方式是绕 X 轴旋转 90 度。
  • 碰撞处理：为目标 mesh 写入 convexDecomposition 碰撞近似，scope=per_component，供下游物理测试加载。
  • 补充碰撞和物理属性后，下游工具可以把资产作为可参与仿真的物体加载，而不是只把它当作外观模型。
  • 针对下游 mesh 缺陷反馈，额外 author 轻量 Physics Proxy Collider：/World/PhysicsProxy/BBoxCollider，视觉 mesh 保持不变。
